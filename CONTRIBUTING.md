# Contribuindo

Boas contribuições deixam o template mais seguro, mais portátil ou mais fácil
de configurar sem depender de uma empresa específica.

Antes de abrir uma PR:

1. Não inclua segredos, domínios reais, dados de clientes ou arquivos `.env`.
2. Mantenha integrações externas opcionais e desligadas por padrão.
3. Rode `npm run build`.
4. Explique o problema e como validou a mudança.

Para vulnerabilidades, não abra issue pública. Siga [SECURITY.md](./SECURITY.md).
